# eZ-Match — дизайн-система

Источник правды по внешнему виду панели. Все новые экраны собираются из описанных
здесь примитивов; если нужного примитива нет — он сначала добавляется сюда и в
`apps/panel/src/components/ui.tsx`, и только потом используется в странице.

Активное направление: **8. Steel** — холодная стальная база, приглушённый синий
акцент, средний радиус. Смена направления — это правка блока `@theme` и двух
переменных `--ppanel-check`/`--ppanel-chevron` в
`apps/panel/src/app/globals.css`; разметка компонентов при этом не меняется.

---

## 1. Токены

Токены живут в `@theme` (Tailwind 4) и доступны как обычные утилиты:
`bg-ink-900`, `text-ink-300`, `border-brand-500`.

| Токен          | Роль                                                     |
| -------------- | -------------------------------------------------------- |
| `ink-950`      | Фон страницы                                             |
| `ink-900`      | Поверхность карточки, шапка, сайдбар                     |
| `ink-850`      | Фон поля ввода, вложенная поверхность                    |
| `ink-800`      | Вторичная кнопка, наведение на строку таблицы            |
| `ink-700`      | Граница карточки и поля в покое                          |
| `ink-600`      | Граница интерактивного элемента (чекбокс, кнопка)        |
| `ink-400`      | Подписи, вспомогательный текст, плейсхолдер              |
| `ink-300`      | Текст лейбла, вторичный текст кнопки                     |
| `ink-200`      | Текст на вторичных поверхностях                          |
| `ink-100`      | Основной текст                                           |
| `brand-500`    | Акцент: главная кнопка, фокус, активная вкладка          |
| `brand-600`    | Наведение на главную кнопку                              |
| `ok-500`       | Живой сервер, LIVE-матч, успешная задача                 |
| `warn-500`     | Предупреждение, `NEEDS_RECHECK`, пауза                   |
| `danger-500`   | Ошибка, разрушающее действие                             |

Правила использования цвета:

- Акцент (`brand-500`) означает «главное действие или текущий выбор». На
  карточках, границах в покое и иконках он не используется.
- Статусные цвета никогда не применяются к кнопкам. Красная кнопка — это контур
  `danger-500/50` на прозрачном фоне, а не заливка.
- Секреты (GSLT, RCON) выводятся `text-ink-400` моноширинным шрифтом и всегда
  замаскированы; акцентом их не подсвечиваем.

## 2. Метрики

| Параметр                | Значение                                              |
| ----------------------- | ----------------------------------------------------- |
| Радиус карточки         | `rounded-xl` (12px)                                   |
| Радиус контрола         | `rounded-lg` (8px)                                    |
| Высота контрола         | 36px (`px-3 py-2` при `text-sm`)                      |
| Шаг сетки               | 4px; отступы внутри карточки `px-5 py-4`              |
| Вертикальный ритм формы | `space-y-4` между полями, `space-y-1.5` внутри поля   |
| Основной шрифт          | system-ui / Segoe UI                                  |
| Моноширинный            | JetBrains Mono → Cascadia Mono → Consolas             |

Размеры текста: `text-sm` — интерфейс по умолчанию, `text-xs` — подписи и
метаданные, `text-base` — только заголовок страницы. Ничего крупнее в панели нет.

## 3. Состояния

Одинаковы для всех контролов:

- **Покой** — граница `ink-700`, фон `ink-850`.
- **Наведение** — граница светлеет до `ink-400` (у кнопок — фон до `ink-800` /
  `brand-600`).
- **Фокус** — `outline-none focus:border-brand-500`. Тени и кольца не
  используем: панель тёмная, тень на ней читается как грязь.
- **Выключен** — `disabled:opacity-60 disabled:cursor-not-allowed`, цвета не
  меняются.
- **Ошибка** — граница `danger-500`, текст ошибки `text-xs text-danger-500`
  под полем.

## 4. Компоненты

### Кнопка

Три уровня, экспортируются из `components/ui.tsx` как готовые строки классов.

```tsx
<button className={buttonClass}>Go live</button>
<button className={secondaryButtonClass}>Пауза</button>
<button className={dangerButtonClass}>Отменить матч</button>
```

- На экране одна главная кнопка. Всё остальное — вторичные.
- Разрушающие действия (удалить инстанс, отменить матч, обновить CS2) — всегда
  `dangerButtonClass` и всегда с подтверждением.
- Кнопка не растягивается на всю ширину, кроме единственной кнопки формы входа.

### Поле ввода и textarea

```tsx
<Field label="Имя сервера" hint="Показывается в списке">
  <input className={inputClass} name="name" />
</Field>
```

`inputClass` подходит и для `textarea` — добавляется только `min-h-24`
и `resize-y`. Поле консольной команды дополнительно получает `font-mono`.

### Выпадающий список

Нативный `<select>`, приведённый к виду поля ввода: стрелка рисуется фоновым
SVG, потому что нативная стрелка в тёмной теме остаётся светлой.

```tsx
<Field label="Режим">
  <select className={selectClass} name="mode" defaultValue="competitive">
    <option value="competitive">Competitive 5v5</option>
    <option value="wingman">Wingman 2v2</option>
  </select>
</Field>
```

Нативный select используется намеренно: он работает с клавиатуры и с экранными
читалками без нашего кода. Кастомное меню оправдано только там, где нужен поиск
по списку (выбор карты из полного пула) — тогда это отдельный компонент
`Combobox`, а не подмена `select`.

### Чекбокс

Нативный `<input type="checkbox">` скрывать нельзя (ломается клавиатура), но
его стандартный вид в тёмной теме нечитаем, поэтому используем `appearance-none`
с собственной галочкой:

```tsx
<label className="flex items-center gap-2.5">
  <input type="checkbox" name="plugins" value="metamod" className={checkboxClass} />
  <span className="text-sm text-ink-100">Metamod:Source</span>
</label>
```

- Метка всегда обёрнута в `<label>` — клик по тексту переключает чекбокс.
- Пояснение к пункту идёт `text-xs text-ink-400` под меткой, а не в `title`.
- Группа чекбоксов — `space-y-2.5`, без рамки вокруг группы.

### Переключатель

Переключатель применяется только там, где изменение вступает в силу сразу
(язык интерфейса `LanguageToggle`, «ножевой раунд» в настройках матча). Если
значение сохраняется по кнопке «Сохранить» — это чекбокс, а не переключатель.

Язык хранится в cookie `ezmatch_locale` (`en` | `ru`) и ставится через
`POST /api/locale`. Переключатель — обычная форма, без client-side JS.
Строки — в `apps/panel/src/lib/i18n/dictionaries.ts`; новые подписи
добавляются сразу в оба словаря.

### Badge

`<Badge tone="ok">running</Badge>` — тон `ok | warn | danger | info | neutral`.
Внутри бейджа только статус, без иконок и без действий.

### Уведомление

`<Notice tone="danger|warn|info">` — ошибка формы, предупреждение перед
разрушающим действием, подсказка. При тоне `danger` автоматически ставится
`role="alert"`, поэтому вручную его дублировать не нужно. Инлайновую вёрстку
цветного `<p>` вместо `Notice` не пишем.

### Чип

`chipClass` — компактная ссылка или кнопка внутри карточки: инстанс в списке
сервера, файл бэкапа. Не путать с `Badge`: чип кликабелен, бейдж — нет.

### Карточка

`<Card>` + `<CardHeader title description action />`. Вложенных карточек нет:
внутри карточки разделяем блоки границей `border-t border-ink-700`.

### Таблица

Заголовок — `text-xs uppercase tracking-wide text-ink-400`, строки разделены
`border-t border-ink-800`. Наведение подсвечивает строку следующей ступенью
поверхности: на фоне страницы это `hover:bg-ink-900`, внутри карточки —
`hover:bg-ink-850`. Числовые колонки выравниваются вправо и набираются
`tabular-nums`.

Таблица — основной способ показать список сущностей: список матчей, статистика
игроков, оружие. Карточка на сущность используется только там, где у записи есть
разнородные метаданные и вложенные действия (сервер с дисками и инстансами).

### Меню навигации

Пункты верхнего меню — `NavLink` из `components/nav-menu.tsx`. Активный пункт
подсвечивается фоном `ink-800`, а не акцентом, и получает `aria-current="page"`.
Счётчик рядом с названием (например, число идущих матчей) — заливка `brand-500`
с текстом `ink-950`.

Раздел с подпунктами — `NavMenu`: кнопка со стрелкой и панель `ink-900` в рамке
`ink-700`. Меню закрывается по клику вне, по `Escape` и при смене маршрута.
Наведением меню не открывается: это ловушка на тач-устройствах.

### Вкладки

Горизонтальные вкладки внутри сущности (страница матча) — это отдельные
маршруты, а не состояние компонента: у каждой вкладки свой URL, её видно в
адресной строке и можно открыть в новой вкладке браузера. Активная вкладка —
нижняя граница `border-b-2 border-brand-500` и текст `ink-100`, неактивная —
прозрачная граница и `ink-400`.

### Консоль

`.console-surface` из `globals.css`: моноширинный шрифт с отключёнными
лигатурами и фиксированной шириной символа, чтобы поток логов не дёргался.
Фон консоли — `ink-950` даже внутри светлой темы. Собственные команды
пользователя подсвечиваются `brand-500`, ошибки — `danger-500`, остальное —
`ink-300`.

### Пустое состояние

`<EmptyState title description action />` — заголовок, одно предложение
объяснения и одно действие. Иллюстраций нет.

## 6. Чего в панели нет

- Градиентов и теней. Поверхности плоские, глубина задаётся только границей.
- Эмодзи в интерфейсе.
- Анимаций, кроме `transition-colors` на наведении и индикатора выполнения задач.
- Модальных окон ради подтверждения: подтверждение — это вторая кнопка на месте
  первой, а не диалог поверх экрана.
