Small bordered pill used for secondary navigation targets — "Show" links in the match table, free-server shortcuts, backup filenames.

```jsx
<Chip href="/admin/instances/3">nl-01 · retake · <span style={{color:'var(--text-faint)'}}>de_mirage</span></Chip>
```

Hover (and `active`) turn border and text to Ignite orange. Never use it for a primary action — that is `Button`.
