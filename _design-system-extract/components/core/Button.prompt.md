Action control for every button in the eZ-Match panel; pick the variant by destructiveness, not by looks.

```jsx
<Button variant="primary">Create match</Button>
<Button variant="secondary" size="sm">Edit</Button>
<Button variant="danger" size="sm">Delete</Button>
```

Variants: `primary` (solid Ignite orange, dark text), `secondary` (bordered surface), `ghost` (bare, toolbars), `danger` (outlined red, never solid). Sizes `sm` (28px, in-table), `md` (36px, default), `lg` (44px, login). Use `block` for full-width form submits, `href` to render as a link.
